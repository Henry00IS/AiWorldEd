# SolidScript

SolidScript builds level geometry from a list of command lines: add a **SolidScript** generator to a solid model, press **Edit Script**, and every line you add turns into solids in the viewport as you type.

## Writing a script

Double-click a command in the palette, or drag it in, to add it below the current line. Double-click a line to change its values. Blocks such as Repeat, Transform or If hold the lines up to their End. Move By, Move To, Rotate By, Rotate To, Scale By, Scale To, Align To, Mirror, Resize and Matrix are flat lines with Of, and do not take an End. A block with nothing inside is no mistake: it does nothing, and the Output shows a ⚠️ warning with a link to its line. With several lines selected whose blocks are whole (every If with its End), double-clicking a block command wraps them: it goes above the first line and its End below the last. When the selection cuts a block, the command goes below the current line as usual.

<details>
<summary>More Details</summary>

- Scripts use the editor's axes: X right, Y up and Z toward the front, so a Cube of `1, 2, 3` is 2 metres tall and `[$Box.Size]` is width, height and depth. Flat paths are drawn with their own X and Y: Linear Extrude lays them on the ground (their Y running to the back) and pulls them up, Rotate Extrude spins them around the upright Y axis with their Y as the height.
- Fields take plain values (`2`, `1, 0, 0`), vectors in brackets (`[20, 30, 10]`, the same as `[=Vector(20, 30, 10)]`; any bracket that works out to exactly three numbers, such as `[[X], 0, 2]`), lists of vectors (`[1, 2, 3], [4, 5, 6]`), variables in brackets (`[Width]`) and formulas after an equals sign (`[=[Width] / 2]`). `%` is the remainder, such as `[=[I] % 2]` giving 0 on even numbers. Every field reads `[names]` and `[=formulas]`, the Name of a building block too (`[Width]` with Width 15 names it `15`; a Solid there stops with `Name needs a Text or Number, not a Solid`). Only fields that name a variable a line writes (Set's Variable, every Into, Top, Sides and the like) or that define a name or setting the editor reads before the run (a Function's name and inputs, a Part's name, the settings of an Input, Input Group and Input Note, and the input a handler, Set Input or Show Inputs When works on) are used as typed; write `$[` for a literal bracket elsewhere. Text inside a formula takes double quotes, such as `[=IsString("3e")]`. Inside a formula every variable and system value stands in brackets, such as `[=[Width] / 2]` or `[=[$Box.Width] * 2]`; a word without brackets is only ever a function, such as `Sin(5)`, so a new function never clashes with a variable name. `[=Width]` stops with a hint to write `[=[Width]]`, and `3e` or `hello` get an error that shows the quoted form. Lists in a formula are written in brackets, the way Echo shows them: `[=Reversed(["a", "b", "c"])]`, `[0, [1, 1, 1], "Easy"]`, `[0]`, `["0"]` or `[]`. A bracket with a comma, one number, one text or nothing in it is a list, while `[Name]` and `[[Name]]` stay names, so a list of one other value is written `List([X])`; `List(a, b, ...)` makes a list of any number of values. In a field the outer brackets of a list are left off: `0, [1, 1, 1], "Easy"`. A name in brackets inside quoted text of a formula is read into the text, so `[="Width [W] mm"]` gives `Width 15 mm`; write `$[` and `$]` for brackets that stay text. Single quotes are kept for later use.
- Only the commas typed in a field separate list items; a value is never split again, so For Each In `[Text], 23` with Text set to `Hello, World` walks `Hello, World` and `23`. Write `$,` for a comma inside an item, such as `a$, b, c` for the two items `a, b` and `c`. `[=Split([Text], ",")]` splits text, `[=Join([List], ", ")]` joins a list, and `[=Parse([Text])]` reads text like a typed field: `4,5,5` gives a vector and `5+5` gives 10.
- A script that builds nothing runs and shows its output with a warning, for trying out lines. An error keeps the output and variables from before it.
- Variables have no declared type, like `var` in other languages: any line may give a variable any kind of value, and a later line another kind. Left empty, a Set's Value gives empty text. **Clear Variable** empties a variable the way that fits what it holds: a list or vector becomes `[]`, a number 0, a Yes/No No and anything else empty text, and a name no line set becomes `[]`; **Delete Variable** forgets it. Commas typed outside brackets in a Value make a list, each item read on its own: `[5,3,4],zu,45,[4,5,6]` is a vector, the text `zu`, the number 45 and another vector, while `2,3,4` is still a vector and one item stays one value. Write `$,` for a comma inside a text, such as `Hello$, World`; `Hello, [Name]` is a list of two items. Clicking the Value of a Yes/No suggests Yes and No.
- Every command declares which kinds each field takes and what each field naming a variable gives. A line given a kind it cannot use stops with a plain message, such as `Of needs a Solid, Face or Text, or a list of them, not a Yes/No`; formula functions declare theirs too, so `Abs()` given a Solid stops the same way. While you type, the editor follows the script without running it and knows what kinds each name may hold at the caret: through If and Else, loops, Functions (per Call, and what each Return gives back) and Parts. An If narrows what it tests: inside `If [Henry] > 3` and its Else, Henry is a number; inside `If IsNum([V])`, V is a Number, and inside `If IsFace([X])`, X is a Face; a branch no run can take, such as `If 1 == 2` or a test a script Input's kind rules out, is skipped. Hover, the **Variables** tab and autocomplete show every kind a name may hold, such as `Number or Text`, each with the write that gives it and its line, such as `Solid: What is made of Cube (line 3).` or `Number: Set to 15 (line 3). Solid: What is made of Cube (line 5).` after an If and Else; clicking a name in the Variables tab goes to the last such write, and a wavy underline only appears where no way through the script gives a usable value.
- Fields that take one of a few words, such as Anchor, Which, How, a generator's choices or a texture name, take a Text or a Number; a Solid or a list there stops the line with `… needs a Text or Number, not a Solid`. A block's Name names everything it builds: a named Linear Extrude, Rotate Extrude or Offset passes its Name to every piece, and without one each path keeps its own; Point only adds a corner, so it has no Name or Into. A Repeat or For Each counter lives in its loop, so a Function called inside the loop does not see it. The editor's hints tell item writes such as `Set Points(0)` as **Set**, not as an input passed in. Mistakes name the line and field and say what to do, such as `division by zero; check that what is divided by cannot be 0` or `a closing ")" is missing at the end`.
- Names ignore case: `[count]` and `[Count]` are one variable, and `sin(65)` is `Sin(65)`. Write them in PascalCase, such as `[StepHeight]`, `[Local.Width]`, `[Persistent.Presses]`, `Function Staircase` and `CharacterCode("A")`, like the examples do; the explorer keeps the spelling of the first Set or Input.
- Functions such as `Sin`, `Lerp`, `Remap`, `Split` or `TimeText` work in formulas; hover one in the suggestions to see what it does, with an example. `%` is the remainder, such as `[=[I] % 2 == 0]` for even numbers. `ItemOr([List], 5, 0)` reads an item with a fallback when there is none. Numbers that are at most 0.001 apart are equal, so `0.1 + 0.2 == 0.3` is Yes; `Equal([A], [B], 0.05)` picks another tolerance. Math of one number, such as `Abs`, `Floor`, `Round`, `Snap`, `Mod` or `Sin`, works on each axis of a vector, so `Floor([$Point])` gives the grid cell; `Min` and `Max` of two vectors give the lowest or highest per axis. `RandomInt(1, 3)` gives 1, 2 or 3, Max included, and takes an ID and Seed like `Random`.
- A Texture field in a line's window has **Pick** and **Type**: Pick uses the same texture picker as the inspector and stores the texture's full library path; Type takes a name, a variable such as `[Wall]` or a formula. A field whose text uses `[` opens on Type.
- A field that takes a direction, such as Clip's Normal, Mirror's Plane Normal, Align To's Direction, Place At Points' Directions, Find On's Direction, Project UVs' Axis or the Normal of the paths, lists **Pick Normal…** among its suggestions when clicked. It opens a small 3D view of a 26-faced shape on the floor grid: one face for each axis, each 45° edge direction and each corner diagonal, coloured by the axes it points along and labelled, such as `+X`, `+X+Y 45°` or `+X-Y+Z`. Drag to orbit and scroll to zoom; hovering a face highlights it, and clicking it writes the way it points, such as `1, 1, 0`, which the field reads as a direction. The same shape is the **Rhombicuboctahedron** generator, whose Precision is Grid Aligned (corners on the grid, every slanted face exactly 45°) or Precise (the true shape with square faces).
- While a field is typed, suggestions follow the caret: a field that takes a few words, such as Which of Select Faces, lists them first; after `[` the matching variables, system values and functions show; inside any call, such as `[=Clamp(`, a hint under the field shows the full signature, such as `Clamp(Value: Number, Min: Number, Max: Number) -> Number`, with the input being typed in bold, that input's kind and meaning, and what the function does; it follows the caret as commas are typed, also in nested calls, and the script's own Functions show their inputs. Fields that name a variable a line writes, such as Set's Variable, every Into, Extrude Face's Top and Sides, Inset Face's Inner and Ring, Scatter Points' Normals, Result In, the List of the list lines and the Counter, Item and Key of Repeat and For Each, suggest the script's variables bare, without `[ ]`, so one can be reused; Inputs, functions and system values are left out. Set's Variable also offers the `$Selected` lists and, after a dot, only what leads to a value a line can set: `Solid.` offers Faces, Edges, Vertices and Data, `Object.Edges.` offers First, Last, Faces, Parent and Data, and a vector variable offers X, Y and Z. Click a suggestion, or press Enter or Tab, to write it at the caret. Entering or clicking a field whose text before the caret ends with `[` (not `$[`) opens the suggestions again.
- **Stop Script** ends the script there, also from inside a Repeat or a Function, and keeps what it built. Run shared lines from many places with a Function and Call. A mistake always stops the script and highlights its line; there is no error catching.
- Shift+click or Shift+↑/↓ selects lines and Ctrl+click picks single lines; dragging any selected line moves them all, picked lines squashed together where they land, as one undo step. Ctrl+C, Ctrl+X and Ctrl+V copy, cut and paste them, also between scripts, and Ctrl+D duplicates them. Space adds an empty line above the current line and moves there; Shift+Enter or Insert adds one below.
- **F4**, **Ctrl+/**, **Off / On** in the toolbar or **Turn Off** in the right-click menu turns the selected lines off and on: they stay, are saved and synced, but do not run. Only the selected lines change: turning off a block line such as If also turns off its End and Else, and the lines inside keep running without the block; turning it on again turns its off End and Else back on when it has no End. Select the block with its contents to turn it all off. An off line is ignored everywhere, not just when the script runs: the names it would set, an off Function or Part, and its fields leave autocomplete, the Variables tab, the kind and mistake checks and the squiggles, and an off Input line shows no input in the inspector. **End** in Logic adds an End by hand when one is missing. A **Note** line holds a comment.
- In the help panel and a line's manual, every block name is a link: clicking it selects that block in the command list, scrolls to it and shows its help. The search is cleared only when it hides that block.
- In a shared room, script edits sync line by line: two people changing different lines both keep their change, the later write wins on the same line, and Undo only reverts your own lines. When someone else edits, your scroll position, current line, selection and an open configurator stay put. Breakpoints stay on your computer; turned-off lines are part of the script and sync.
- The script has its own undo history, apart from the level's: while the editor has focus, Ctrl+Z undoes and Ctrl+Y or Ctrl+Shift+Z redoes script edits only (typing, inserting, deleting, moving, Off/On, a line window's OK, paste), and level undo never changes the script.
- **New** starts an empty script and **Examples…** opens a ready one; both can be undone with the script's undo.

## Running and debugging

The script runs on every change. **Start** builds everything, **Debug** builds one solid at a time, **Step** builds the next one, and **Stop** shows the whole script again.

<details>
<summary>More Details</summary>

- A script may make at most 10,000 solids, a mesh may have at most 1,000,000 triangles, a list may hold at most 100,000 items, functions and parts may run 256 levels deep, Repeat and For Each run at most 10,000 rounds, and a run stops after 10,000,000 steps of work. A line that hits a cap names the line and what to change.
- **F9** sets a breakpoint on the current line; Start and Debug pause before it runs.
- **Ctrl+F10** builds up to the line at the cursor.
- **Trace** marks the lines the debugger has passed.
- A small **×N** at the end of a line says how often it ran; hover it for its time.
- Drag the splitters beside the palette, beside the help column and above the output to resize them; the editor keeps the sizes for next time.
- The inspector's **Script** row shows the script's size and, under it, its messages: why the script may not be used in this step (such as a modifier-only script in a generator), then the script's error in red directly below; with neither it shows no message.
- The **Settings** tab holds **Can Be Used As** (Generator, Modifier; the use of the step you opened stays on, as in the inspector) and an **Author** line saved with the script. Both are script edits, so Ctrl+Z in the editor undoes them.
- The **Variables** tab lists every name with its value at the step shown, and the **System** values such as `$Time.Year`, `$Editor.Version` or `$Box.Width`. `$Box` is the generator or the modifier volume: `[$Box.Width]`, `[$Box.Height]`, `[$Box.Depth]`, `[$Box.Size]`, `[$Box.Extents]`, `[$Box.Min]` and `[$Box.Max]` describe its box, and `[$Box.Position]`, `[$Box.Rotation]` and `[$Box.Scale]` are its pose in the level, in metres and degrees. The examples size themselves from the box. Where a script runs without a box, such as in the assistant, the size values read as 1 and the Output shows a ⚠️ warning on the line instead of stopping; Position, Rotation and Scale then read as the origin, no turn and a scale of one.

</details>

## Inputs

**Input** lines become fields in the inspector, so the same script builds many variants: a staircase with a Steps count, a column with a Height.

<details>
<summary>More Details</summary>

- A **curve** input opens the curve editor; read it with `CurveAt(curve, x)` or `ProfilePoints(curve, height, radius)`.
- A **texture** input picks a library texture; wrap solids in a **Texture** block, such as `Texture [Wall]`, to paint every face with it. The 🔁 Texture may change per object, such as `[=Pick([$Index] % 2, "grass", "stone")]`. An inner Texture block wins, and solids outside keep the generator's texture. **Texture Faces** gives the faces Select Faces picked their own texture. **Project UVs** gives them coordinates from a Box, Planar, Cylinder or Sphere projection (Box, the default, uses the Overhead, Front or Side view each face faces most). **Unwrap**, **Pack Islands** and **Transform UVs** lay those islands flat, pack them into 0 to 1, or move, scale and rotate them. Transform UVs Pivot Each Face turns and scales each face's UVs about their own middle, rather than the middle of them all. Transform UVs Offset is tiles of U and V, and on solids from Input Objects it shifts the texture of that copy; Readable Text keeps lettering readable on a mirrored copy, and Textures is Move With Shape or World Aligned, so any solid can use those options. Solids stay solids; meshes stay meshes.
- **Input Group** shows the inputs inside it under a heading, **Input Row** puts them side by side, **Show Inputs When** shows them only while another input has a given value, or any one of several values written with commas, and **Input Note** shows a line of text among them.
- When Input Changes and When Button Pressed blocks can check and change inputs.
- **When Baked** runs just before the generator is baked, so a light preview can bake as a detailed version; undo brings back the old inputs.
- Values stored as `Persistent.Name` stay between runs.

</details>

## Solids, faces and points

Solids, faces, edges and corners are values, like numbers and text. A dot reads their parts: `[Top.Normal]`, `[Face.UVs]`, `[Object.Mode]`, `[Object.Faces.Count]`, `[Edge.Length]`, `[Faces.Center]` of a whole list, and `[Object.Vertices.Positions]` through a list. `[Face.Id]`, `[Edge.Id]` and `[Vertex.Id]` are the whole numbers `[$Id]` reads. `[Face.Texture]` is the library texture a face gets (empty for the generator's texture) and `[Object.Textures]` lists those an object uses, so Select Faces Where `[=[$Face.Texture] == "Brick"]` picks the brick faces. `[Edge.SignedAngle]` is the angle between an edge's faces, positive on an outer corner and negative on an inner one, and `[Edge.IsConvex]` is Yes on an outer corner, so Bevel Edges Where `[=[$Edge.IsConvex]]` rounds only the outside. On one vertex it is `[Vertex.Position]`; the singular after Vertices is a mistake, because Vertices is a list. Set `[Face.UVs]` to a list of U and V pairs, one per corner; a solid face must have a planar mapping or the line stops. `[Object.Mode]` is Additive, Subtractive or Intersecting: the effective CSG mode of the solid in the output, including when Mode was left empty and inherited (Additive inside a Group or Part, otherwise the generator or modifier Operation). Set `[Object.Mode]` to one of those words to change it. `[Face.Data.Height]` keeps your own values on one. Set through a list writes every item, so Set `Object.Edges.Data.Kind` to `trim` marks every edge of a solid, and `[Object.Edges.Data.Kind]` reads one value per edge. A Value that reads `[$Item]` or `[$Index]` is worked out once per item, such as `Object.Faces.Data.Height` to `[=[$Index] * 0.1]`. System values start with `$`: `[$Selected.Faces]` is what the last **Select Faces** picked, `[$Selected.Objects]` what the lines below work on, `[$Input.Objects]` what a modifier receives. In a **Select Faces** Where condition the face being tested is `[$Face]` and `[$Index]` is its number from 0; **Select Edges** uses `[$Edge]` and **Select Vertices** uses `[$Vertex]`. `[$X]`, `[$NZ]` and the other short fills stand for `[$Vertex.Position.X]`, `[$Face.Normal.Z]` and so on. Fields worked out once per element, such as **Where** on Select Faces and **Distance** on Displace, show a green path and a 🔁 icon in the inspector and in the script listing. `.Data` holds only your own values; built-in facts are members such as `[Face.Normal]` and `[Face.UVs]`.

<summary>More Details</summary>

- **Select Faces** picks faces into `[$Selected.Faces]` and into its **Into** variable. Which is a preset that equals a written-out Where: **All** keeps every face, **Facing Up** equals `Facing([$Face.Normal], Vector(0, 1, 0))`, and **Top** equals `HasTag([$Face.Tags], "Top")`. Which **Between** keeps the faces between this Select Faces and the previous one. **Where** is a condition each remaining face must pass, with `[$Face]`, `[$Index]` (its place in the list) and `[$Count]`. Left off, it keeps what Which picked. Where helpers such as `Facing()`, `InBox()`, `Near()`, `EveryNth()`, `HasTag()` and `Chance()` work in Where, If and every other condition field. There is no Select In Box command; use `InBox()` in Where, such as `[=InBox([$Face.Center], Vector(0, 0, 0), 2)]`. To test whether a solid, face or edge meets a box, use `HitsBox([$Object], Center, Size)` or `Hits([$Object], [Wall])`, with How `Touching` (the default: any contact), `Overlapping` or `Fully Inside`. To pick faces of one solid, set Of, such as Of `[Knob]` or a Name. To walk a pick later, write it Into a variable and For Each over that list: `[$Selected.Faces]` is the last Select Faces, including one made inside a loop. Select Objects, then Select Faces, then Select Edges narrows: faces of the picked solids, then edges of those faces. Empty Of on Select Edges uses `[$Selected.Faces]` when faces are picked.
- **For Each** walks any list: For Each `[Face]` In `[$Selected.Faces]`, with an optional **Key** for its number. In a Data value it walks the keys. `[$Selected.*]` carries from round to round and stays after End, so a later round can add to or move what an earlier round picked. Write a pick Into a variable when you want to keep it through later Select lines.
- Every face command takes **Of**: a face, edge, solid, a list of them, or a solid **Name** such as Knob (in any case, also the shapes of a Part by its name). Empty takes `[$Selected.Faces]`. See the Panel With Knobs example.
- **Place On Face** builds the shapes inside standing on its face the way they stand on the ground (Y out of the face), with a Lift.
- **Place At Points** builds the shapes inside at each point in At, a list of vectors such as `[Spots]` from Scatter Points. Optional Directions (one direction for all points, or one per point such as the Normals list) turns up along that way, optional **Forward** turns the front (Z) toward a second direction, laid square to up, so a fence post stands up and faces along a path, and Lift moves them out along up. Align To has the same Forward. **Build** One Line builds only one of the lines inside at each point, the one **Choice** picks (from 0, wrapping so -1 is the last; random per point by default), to scatter variants such as three kinds of rock. Directions, Forward, Lift, Align To Normal, Rotation and Scale can change per point, with `[$Point]` (its Position and Normal). Optional **Where** is a condition a point must pass to get a copy, such as `[=[$X] > 0]` or `[=EveryNth([$Index], 2)]`; points left out keep their `[$Index]`, so Choice and Random stay the same.
- Pick faces, edges or vertices with **Select Faces**, **Select Edges** or **Select Vertices**, then operate: **Extrude Face**, **Scale Faces**, **Inset Face**, **Bevel Edges**, **Delete Faces**, **Texture Faces** and **Project UVs** use that pick when **Of** is empty. **Extrude Face** names its new solids (**Into**), their end faces (**Top**) and side faces (**Sides**); **Scale Faces** scales each picked face about its center (a solid stays a solid); **Inset Face** names **Inner** and **Ring**; **Bevel Edges** names its new faces and skips edges of faces it made itself; it works on solids and meshes, its **Distance** may change per edge, and a 🔁 **Where** picks edges. **Bevel Vertices** cuts corners of a mesh off, Distance along each edge that meets them. **Inset Face**, **Delete Faces**, **Delete Edges** (the faces along the edges) and **Delete Vertices** (the faces around the corners) work on a mesh; a solid stops, with a hint to wrap it in **Mesh From Solids** first, and a mesh with no faces left is taken out. **Delete Objects** takes whole solids and meshes out. Every line with an **Of**, except Output, has a 🔁 **Where** each item of Of (or of the selection an empty Of uses) must pass for the line to work on it; left off, it works on all of them. Faces read `[$Face]`, edges `[$Edge]`, corners `[$Vertex]`, objects `[$Object]`, and every item `[$Item]`, `[$Index]` and `[$Count]`. Every Delete line has a 🔁 **Where** an item must pass, such as Delete Objects Where `[=[$Object.Center.Y] < 0]`. **Shade Smooth** shades the faces of the objects in **Of** (empty: `[$Selected.Objects]`) smoothly where they meet at less than **Angle** degrees (60), keeping sharper edges hard; its 🔁 **Where** picks faces, such as the sides only, and Angle 0 makes them flat again. Smooth solids of one script blend where they touch. It works on solids for now. **Join Meshes** joins the meshes in **Of** into one; **Merge By Distance** afterwards welds the corners that touch.
- **Scatter Points** spreads points into a list of positions. **On** chooses how: **On Faces** (the default) spreads them over faces, more on bigger ones, and writes **Normals**; **Inside** fills an object; **In Box** fills a box of Size; **Grid** lays Counts points in that box. **By** chooses how many: **Count** gives that many, **Density** gives so many per square metre on faces (it can change per face, such as `[=Max(0, [$Face.Normal].Y) * 20]` for more on flat ground) or per cubic metre inside, so a bigger shape gets more. **Spacing** keeps points at least that far apart and gives as many as fit. Unused fields stay hidden, also those under a hidden choice. Of empty uses [$Selected.Faces]. The same Seed gives the same points for the random modes.
- **Hull** wraps the solids, Point lines and optional **Points From List** between it and its End in one convex solid. Hand it the list Scatter Points writes, such as `Hull` From `[Spots]`, to wrap those points; they must not all lie in one plane, so scatter on more than one face. **Polyhedron** also wraps a point list, when you are listing corners yourself.
- **Find On** looks at the faces in Of, or [$Selected.Faces] when Of is empty: **Closest** (the default) picks the nearest point to From, **Along Ray** follows Direction and picks the first face it meets. It can write the point, Distance, Normal, Face and Hit. Give From a list of points, such as `[Spots]`, or Direction a list of directions, and it finds once per item: Into, Distance, Normal and Hit become lists with one entry per item (a miss gives 0, 0, 0, 0 and No), and Face gets the faces that were hit, so one line drops every scattered point onto the ground below.
- **Clip** cuts the objects in Of, or [$Selected.Objects] when Of is empty, with a plane. Through is a point on the plane. Normal is the way the part you cut away faces; the other side stays. A solid stays a solid, a mesh stays a mesh, and a closed mesh gets a new face over the cut. The faces Clip makes over the cut are tagged `Cut`, so a later Where can pick them with `[=HasTag([$Face.Tags], "Cut")]` or skip them, such as Scatter Points on everything but the cap.
- **Transform** changes the space that the lines between it and its End work in. Move, Rotate and Scale on that line are applied in that order after On. On takes a face (the same frame as Place On Face) or a solid (its center with world axes); leaving On off keeps the parent space. What the lines build is stored in ordinary script space. Transform never groups solids for CSG.
- **Move By**, **Move To**, **Rotate By**, **Rotate To**, **Scale By**, **Scale To**, **Align To**, **Mirror**, **Resize** and **Matrix** are flat lines with **Of**: they change the objects or points already named there, or `[$Selected.Objects]` when Of is empty. Without Into the change happens where the items already are; with Into the originals stay and the copies are only in that variable. A building block with Into, such as Cube or Input Objects, also keeps its result only in that variable; Output stamps it into the world. An Into that names new faces, edges or points, such as Bevel Edges' Into, Inset Face's Inner and Ring, or Extrude Face's Top and Sides, is only a label: the tool still edits in place and the result stays in the world. Define Part is a variable that builds nothing on its own. **Move By** is a distance in metres in the current space, always literal, no matter how small the solids are. **Move To** places the combined center (the middle of the box around the selection, the same middle a Center, Center, Center anchor uses) at a point in script space. **Rotate By** turns around the origin of the current space; **Rotate To** turns around that combined center. **Scale By** multiplies size from the origin of the current space; **Scale To** stretches about the combined center to an exact size in metres. **Align To** turns Of so its up (Y) points along a direction, such as a face's `[Face.Normal]`. **Resize** also stretches Of to an exact size, about the origin of the current space, and can keep proportions or leave an axis alone. **Matrix** applies a 3 by 4 matrix, including shear. **Rotate By** and **Scale By** have **Around**: Origin (the default) works about the origin of the current space, Combined Center about the middle of everything in Of, and Each Center turns or scales every item about its own middle, in place, like rotating each rock of a scatter. **Array** copies the objects in **Of** so there are **Count** in all, the original first: **Shape** Line puts each copy **Offset** further than the one before, Circle turns them evenly around **Axis** through **Center** over **Angle** degrees (a whole 360 leaves no copy on top of the original), and Along Path spreads them evenly by length along a **Path**, turning each with **Align**. Its **Into** holds only the copies.

</details>

## Fields that change per item

**Set Positions** moves each corner in Of To a position worked out per corner, plus an optional **Offset** added after it, so Offset `0, 0.5, 0` lifts the picked corners without writing `[=[$Vertex.Position] + …]`. Every corner reads the shape before the line, so moving one never changes what its neighbours see.

Many fields can change per item: a Where condition, Displace's Distance, Extrude Face's Distance, Place At Points' Lift, Move By's By and more. Write a formula that reads a per-item value and the field is worked out once for each item; its caption gets 🔁 and green caps. A field that reads none is worked out once for all items.

- Every per-item field has `[$Index]` (the item's place in the list, from 0), `[$Id]` (a whole number that stays with a face, edge, vertex or point, worked out from where it is, so deleting or reordering other items keeps it; for other items it is `[$Index]`) and `[$Count]` (how many items there are), and the item itself: `[$Face]`, `[$Edge]`, `[$Vertex]`, `[$Object]`, `[$Point]` or `[$Item]`.
- `[$X]`, `[$Y]` and `[$Z]` are the item's position: a vertex or point position, or the center of a face, edge, solid or other item. `[$NX]`, `[$NY]` and `[$NZ]` are the normal of a face, vertex or point. In Place At Points, `[$Point]` has a Position and a Normal.
- The Where helpers are made for these fields, and the formula editor shows them first, under **Where**. Their inputs default to the item: `Random(0.5, 2)` gives each item its own number (ID `[$Id]`, Seed 0, so the number stays with its face when other faces go), `Random(0, 90, [$Index], 1)` another one that does not follow it, `Chance(0.3)` says Yes for about 3 in 10 items, `Spread(0, 90)` steps evenly from 0 to 90 over the items, and `Along([$Face.Center], [$Face.Normal], 0.5)` is a point half a metre out from a face.
- Examples: Extrude Face By `[=Random(0.2, 1)]` pulls each face out its own distance; Select Faces Where `[=Chance(0.5)]` keeps about half the faces; Place At Points Lift `[=[$Index] * 0.1]` stacks the copies like stairs; Move By `[=Vector(0, [$Index], 0)]` moves each solid in Of up by its number.

## Paths and meshes

A **Path** is a line of 3D points, open or closed. **Path** draws one along a **Line**, **Arc**, **Spiral** or **From Points**, and **Square**, **Circle** and **Polygon** draw closed ones. **Linear Extrude**, **Rotate Extrude** and **Offset** fill any closed Path drawn inside them, and **Sweep Along Path** sweeps a circle or your own profile along any Path, such as a rail or a pipe. **Scale** sizes the profile at each path point, with `[$Index]` and `[$Count]`, so a horn or vine can taper. `[Path.Points]` is its list of points, `[Path.Closed]` says whether it is closed, and `IsPath(value)` checks for one. Where points are asked for, a Path or vectors in brackets separated by commas both work, such as `[0, 0, 0], [1, 0, 0], [2, 1, 0]`; a Profile ignores z.

<details>
<summary>More Details</summary>

- Each stretch becomes one solid, cut on the mitre so the pieces meet; **As Mesh** builds one mesh instead.
- **Path** writes a Path to Into (Path by default); inside Linear Extrude, Rotate Extrude or Offset a closed Path is filled instead. Shape **Line** (the default) walks from From to To; **Arc** turns around Center facing Normal, from Start by Sweep degrees; **Spiral** also climbs Height and can change radius over Turns; **From Points** uses the corners in Points, and Radius rounds them (Sides segments on each corner, Closed joins the last back to the first, on Arc too). Count is how many points Line, Arc and Spiral write. Unused fields stay hidden.
- `Resample(points, count)` spaces points evenly along a path, `ResampleEvery(points, distance)` places them a fixed distance apart (the end stays as a shorter last step), and `PathLength(points)` measures it. `PathAt(points, amount)` and `PathDirection(points, amount)` give the point and the way the path faces at a fraction of its length, and `TrimPath(points, start, end)` keeps one stretch.
- `Noise(position, scale, seed, detail, roughness, type)` is a smooth layered random field from 0 to 1 (type Smooth, Ridged or Terrain), `NoiseVector` gives three at once, `Voronoi(position, scale, seed, output)` gives cells (Distance, Edge or Cell), and `Hash(value, seed)` is a number from 0 to 1 from any value. `Random(min, max, id, seed)` can be two vectors, `Shuffle(list, seed)` shuffles a list, and `Nearest(points, point)` is the index of the closest point. `RotateVector(vector, axis, degrees, center)`, `Angle(a, b)`, `ProjectOnPlane(point, through, normal)`, `ProjectOnto(vector, direction)`, `RotateEuler(vector, angles)` and `Reflect(vector, normal)` work on vectors. For a yes-or-no chance, write `Chance(0.3)`. `SmoothMin(a, b, distance)` and `SmoothMax` blend without a corner, `PingPong(value, length)` bounces between 0 and Length, `Remap` stays inside its target range unless its last input is `false`, `Accumulate(list)` gives running sums, and `<`, `<=`, `>` and `>=` on two vectors are Yes only when every axis holds.
- Matrix formulas: Transform(move, rotate, scale) makes four rows of four numbers; Invert undoes it, TransformPoint places a point, TransformDirection turns and scales a direction without moving it, and MatrixMove/MatrixRotate/MatrixScale read its parts.
- **Grid Mesh** builds a mesh of quads in a plane: Size is width, height and depth, with one length at 0 so the grid is flat (2, 0, 2 on the ground, 2, 2, 0 for a wall facing the front). Columns and Rows are how many faces there are, and Anchor works like Cube.
- **Mesh** and **Mesh From Solids** are the way a shape becomes a mesh. **Mesh From Solids** bakes the solids between it and its End into one mesh, cutting them the same way the editor does, including Subtractive and Intersecting modes and Group; only the solids inside the block are baked. **Subdivide**, **Smooth Mesh**, **Displace**, **Flip Faces**, **Triangulate**, **Split Edges** and **Merge By Distance** then change that mesh; a solid stops, with a hint to wrap it in **Mesh From Solids** first. **Displace** moves the vertices Select Vertices picked, or every point when none are picked. **Flip Faces** and **Triangulate** take faces or meshes in Of and filter each face with Where; empty Of uses selected faces, else all faces of the selected objects. Triangulate keeps UVs and face tags on every triangle. **Split Edges** takes edges, faces or meshes in Of and filters each edge with Where; it copies corners only where faces around them are cut apart, so the sides can move apart without pulling one another.
- **Mode** on **Mesh** or **Mesh From Solids** works like on solids, but among meshes: **Subtractive** cuts the closed mesh out of the meshes before it on its level and **Intersecting** keeps only their overlap; a **Group** with either Mode cuts with all its meshes at once. Meshes never cut solids, and solids never cut meshes.

</details>

## Generator or modifier

A script can be a **generator**, which builds new geometry from nothing, or a **modifier** on an object or group, which works on what it is added to. **Can Be Used As** on the Script row says which uses a script allows, and **If Used As** lets one script do something different in each.

<details>
<summary>More Details</summary>

- Generator is on for every script that sets nothing. A script that does not allow a use is refused there with a message saying which box to turn on; the use a step already has stays on.
- Add a SolidScript modifier from **Add Modifier** on an object, group or modifier volume. The old generators still cannot go on solids or groups.
- As a modifier, the solids it receives pass on unchanged unless the script has an **Input Objects** line. What the script builds is added, with the script origin at the center of what it receives; Operation picks whether it is added, cut out or intersected.
- `[$Script.Usage]` is Generator or Modifier. `[$Script.Mode]` is Additive, Subtractive, Intersecting or Pass-Through: the generator node's or modifier host's mode in the scene. `[$Input.Objects]`, `[$Input.Faces]`, `[$Input.Min]`, `[$Input.Max]`, `[$Input.Size]` and `[$Input.Center]` describe what a modifier receives (all zero for a generator), and **Input Shapes** builds copies of those solids to move, mirror or cut.
- The **Pedestal** example works both ways: as a generator it builds a box on a slab, as a modifier it puts the slab under the solid.
- **Input Objects** passes the received solids on, with their textures and materials. A **Transform** around that line, or a **Move By**, **Move To**, **Rotate By**, **Rotate To**, **Scale By**, **Scale To**, **Mirror**, **Resize**, **Align To** or **Matrix** of the copy, moves it. The first one that runs changes them; each later one adds a copy. To keep textures where they are in the world, or shift the texture of a copy, or keep lettering readable on a mirrored copy, write the solids Into a list and use Transform UVs Textures, Offset and Readable Text Of that list. Clip of [$Input.Objects] above this line cuts the received solids the same way. **Built-In Modifiers** in the Examples window rebuilds Shear, Linear Array, Radial Array, Transform Array and Mirror this way, including Mirror Bisect and Flip. They match the built-in inspectors; a few behaviours still differ (the arrays measure the whole input, not each piece; Mirror places its plane on the received solids, not the modifier volume box).

</details>

## Examples

The **Examples** window holds showcase scripts such as the Spiral Staircase, small lessons (an irregular rock from Hull, a tapered box, a rounded rail, a hilly floor), and the built-in generators and modifiers rebuilt line by line, so you can see how they work and change them.

- Extrude Face has a per-face Direction (empty uses the normal). Individual Yes, the default, pulls every mesh face on its own; No pulls touching faces as one region, with walls only around its border. At a corner shared by several picked faces, the move is their average. On solids, negative Distance builds a Subtractive slab sunk into the solid, never a mesh. Top and Sides keep the faces the line made.

- Sort List has an optional per-item By, such as [=[$Y]] for height or [=Random(0, 1)] for a seeded shuffle. It evaluates every key before sorting, keeps the order of equal keys, and Biggest First reverses the comparison. Without By it orders the items themselves.
- Warn adds its Message, with [Name] and [=formula] filled in, to the warnings in the Output and inspector and keeps running. Kind Stop ends the script with that message as its error. Put it inside If to warn only on bad input.
- List(index) stops when the index is not in the list and names the valid range. ItemOr(list, index, fallback) returns its fallback instead. ItemClamp(list, index) uses the first or last item outside the range. ItemWrap(list, index) wraps around, so -1 is the last item and Count is the first; [=ItemWrap([Points], [$Index] + 1)] reads the next point of a closed loop.
- **Points** writes Count points to Into, a list of vectors. Its 🔁 At is worked out once per point with [$Index] (from 0) and [$Count], so [=Vector(Cos([$Index] * 45) * 3, 0, Sin([$Index] * 45) * 3)] makes a ring without Repeat and Add Item. Count 0 makes an empty list.
- **Randomize** gives every object or point in Of (empty: [$Selected.Objects]) its own random move of up to Move metres either way per axis, turn of up to Turn degrees either way, and one Scale factor between the two given (such as 0.8, 1.2), about its own center. ID ([=[$Id]] by default) and Seed pick the numbers, so the same ID and Seed always give the same change and deleting one item keeps the rest. It has Where and Into like the other transform tools.
- **Points From Path** spreads points along a Path or point list into Into: By Count (Count points from start to end) or By Spacing (one every Spacing metres, keeping the end). A closed Path does not repeat its start. Optional Directions gets the way the path runs at each point (use it as Place At Points Forward), and Amounts how far along each is, 0 to 1; times PathLength([Path]) that is the distance along. To read a path by metres, write PathAt([Path], [Metres] / PathLength([Path])).
- Select Faces, Select Objects, Select Edges and Select Vertices have an optional **Rest**. It writes the items the line looked at but did not pick, such as Select Faces Facing Up Into [Top] Rest [Sides], so one line splits them in two, like Separate Geometry.
- **Separate Mesh** cuts the faces in Of that pass its 🔁 Where (empty Of: [$Selected.Faces], else all faces of [$Selected.Objects]) off into a new mesh with the same Name, texture and mode. The faces left stay in the old mesh. Into gets the new meshes and Rest the old ones. A mesh whose faces all go stays whole, and a solid stops with the Mesh From Solids hint.
- [Face.Island] is the number of the island (faces joined through shared edges) a face belongs to in its object, from 0 in the order of [Object.Islands], so a per-item field can vary per island, such as Texture Faces Texture [=Pick([$Face.Island], "Brick", "Stone")] or Select Faces Where [=[$Face.Island] == 1]. Blocks that bake their lines (Mesh From Solids, the extrudes, Hull) bake the latest version of what lines inside them built, including later Move By or Set Positions edits.
- To swap one texture for another, as Replace Material does, repaint only the faces that have it: Texture Faces Texture "stone" Of [Wall] Where [=[$Face.Texture] == "brick"].
- Nearest takes an optional Skip index, as Index of Nearest does: Nearest([Points], [$Point], [$Index]) is the nearest other point, never the point itself, and -1 when there is no other.
- Find On has Target (with Closest: Faces, Edges or Corners), Max Distance (a find further away is a miss; empty finds at any distance) and Sample, a 🔁 value read on the face found with [$Face] and written to Sampled, one per item for a list, such as Find On Along Ray From [Spots] Direction 0, -1, 0 Sample [=[$Face.Texture]] Sampled [Ground].
- Blur Data Key Heat Rounds 3 Of [Faces] averages a .Data number or vector of each face, edge or corner with its neighbors (faces sharing an edge, edges or corners sharing a corner, among those in Of), as Blur Attribute does; every round reads the round before, and empty Of uses [$Selected.Faces].
- Array numbers what it makes under .Data.Copy: 0 for the original and 1 on for each copy, as Duplicate Index does, so a later line can vary by it, such as Move By [=Vector(0, [$Item.Data.Copy] * 0.2, 0)] Of [Copies].
- The 🔁 Count of Array may vary per object, with [$Object] and [$Index], as Duplicate Elements Amount does, such as Count [=[$Index] + 2].
- Merge By Distance has Mode All (any corners closer than Distance) or Connected (only the two ends of an edge shorter than Distance, so separate parts that nearly touch stay apart), and a 🔁 Weld Where a corner must pass to be welded, such as [=[$Vertex.Position.Y] > 0].
- Sweep Along Path has a 🔁 Twist: degrees the profile turns about the path at each path point, such as [=[$Index] * 15] for a twisted rope; As Mesh suits it best, since a twisted stretch bends its sides.
- Sweep Along Path As Mesh has Fill Caps (Yes by default): No leaves the two ends of an open path open, like a tube.
- Tag Faces Roof gives the faces in Of (empty: [$Selected.Faces]) a tag of your own, which [$Face.Tags] and HasTag then find and which stays through moves and cuts, as Face Set does; the 🔁 Tag may change per face, and Remove takes it off again.
- Scale Faces has a 🔁 Center (left off: the center of each face) and a 🔁 Axis that scales only along that direction, as Single Axis does, such as Axis 1, 0, 0 to make faces narrower but not shorter.
- Scatter Points On Faces writes to Rotations, when named, the turn that stands a shape up on the face under each point, in X, Y, Z degrees as Rotation reads them, as Distribute Points on Faces does.
- Align To has Axis (X, Y or Z: which axis of the items points along Direction, Y by default) and Amount (0 to 1, the share of the turn to take, so 0.5 leans halfway), as Align Rotation to Vector does.
- RotateBy(rotation, by, local) composes two X, Y, Z degree turns, as Rotate Rotation does: By turns in world space, or in the rotated space when Local is true, which adding the angles does not do.
- For Each has a 🔁 Where an item must pass, with [$Item] the item, for the lines inside to run for it, such as Where [=[$Item.Normal.Y] > 0.5]; Key still counts in the whole list.
- Function inputs may have defaults, such as W, D = 1: a call may leave those off, and they take the value after =. Numbers, Yes/No, quoted text and [lists] are read as values. Inputs with a default come last.
- A Function reruns for each item when its formula is used per item, such as in a Where or a per-face field: [Local.X] holds that item's value each time.
- Scatter Points Ids writes a steady number for each point, worked out from where it lies, so Random seeded by it stays with a point when Count grows or other points are removed.
- Path From Points Radius can change per corner with [$Index] and [$Point], such as [=[$Index] * 0.1]; a corner with 0 stays sharp. Limit Radius Yes shrinks radii that do not fit so rounded corners never overlap.
- Path Shape Smooth bends a gentle curve through every point in Points (Sides segments per stretch, Closed joins the ends); Shape Bezier runs From to To, leaving From toward From Handle and coming into To from To Handle, with Count points.
- Path From Edges joins edges that share corners into a list of Paths (closed when they go all the way round, broken where three or more meet); Path From Faces gives the edges round each face as a closed Path. Both take Of and Where.
- Fill Paths builds a flat mesh of triangles that fills closed Paths (or one loop of points): a path inside another is a hole, one inside that is filled again. The mesh faces the way the biggest path runs round.
- Unwrap Seams [=[$Edge.Angle] > 45] cuts the UVs open only along edges that pass it: faces joined by other edges stay in one island, each folded open from its neighbour so lengths and angles stay true.
- Subdivide Crease [=[$Edge.Angle] > 60] keeps edges that pass it sharp while Smooth rounds the rest; Keep Corners holds the corners of an open mesh in place.
- Extrude Edges pulls mesh edges out into new four-sided faces, Distance metres along Direction (or the way the faces at each corner face), sharing corners so a chain becomes one strip; the new faces are picked.
- Number helpers: Log(number, base) takes any base (10 when left off); Sinh, Cosh and Tanh work per axis; Gcd and Lcm of whole numbers; Xor of two tests; BitAnd, BitOr and BitXor; Median, Range and StdDev of a list of numbers.
- Waves and coordinates: Smootherstep(edge_low, edge_high, value); Saw(value) and Triangle(value) repeat every whole step; Checker(position, scale) gives 1 in odd squares of a checkerboard; FlipToward(vector, reference); FromCylinder(radius, degrees, height), FromSphere(radius, yaw, pitch), ToCylinder(vector) and ToSphere(vector) around the up (Y) axis.
- Random turns: RandomDirection(id, seed) gives a unit direction and RandomRotation(id, seed) an evenly spread rotation in degrees (X then Y then Z); in a per-item field the ID is the item. First(list, count) and Last(list, count) take several items.
- Ranges and slices: Clamp(value, min, max) swaps reversed limits; Lerp(from, to, amount) accepts a vector amount when blending vectors; Slice(list or text, start, count) also takes characters of text, counted from 0.
- Points From Path: a Count of 0 or 1 is raised to 2, so both ends of the path always get a point.
- DivFloor(a, b) divides and rounds down, below 0 too, so DivFloor(a, b) * b + Mod(a, b) is a; Round(a / b) and Ceil(a / b) round the other ways. Facing() is the way to compare two directions by angle.
- Remap(value, from_low, from_high, to_low, to_high, clamp, steps): Steps makes the result jump between that many even levels; 0 or left off slides smoothly.
- Remap also takes Ease after Steps: Linear (the default), Smoothstep or Smootherstep. The latter two blend gently at the edges.
- Star (2D Shapes) draws a flat star: Points tips at the Outer radius, an inner corner at the Inner radius halfway between each two, Twist turning the inner corners in degrees, and Anchor like Circle.
- Path Line by direction and length: set To to Along(From, Direction, Length). Path Spiral turns clockwise from above with negative Turns.
- Nearest(points, point, skip, groups, group): Groups gives a group number per point and Group the one to search, so only points of the same group are found.
- Scatter Points By Density: each triangle draws from its own random stream, so raising Density keeps every point a lower Density gave and only adds more.
- Pack Islands: faces that share a corner with the same UV, such as faces Unwrap Seams kept joined, now pack as one island; Margin (default 0.001) is the gap between islands as a share of the square.
- Texture Faces works on meshes: each texture becomes one of the mesh's texture slots and each face points at its slot; one slot is the whole-mesh texture as before.
- Icosphere Mesh: a mesh sphere of even triangles with Radius and Subdivisions (1 to 7), and a matching Icosphere generator for the world editor; both share one shape module.
- MatrixMultiply(a, b), MatrixDeterminant(matrix) and MatrixTranspose(matrix).
- Corner values: [Face.Angles] gives the angle at each corner in degrees, in vertex order; [Vertex.IsUVSplit] and [Edge.IsUVSplit] tell whether the faces there give different UVs.
- Cluster(points, distance, groups) groups close points, giving each the index of the point its cluster started from.
- Merge Points welds mesh corners that share a Merge ID into one at their average position, with Pick Where.
- Scale Faces scales faces that share corners as one island, by their average Factor about their average Center.
- Scale Edges grows or shrinks edges, joined ones as one island about their average midpoint.
- InvertRotation, RotationAxis, RotationAngle and MixRotation work on turns in X, Y, Z degrees.
- Select Shortest Paths picks the edges of the cheapest way from Start corners to the nearest End corner, with a Cost per edge.
- Face Groups splits faces into groups joined through edges, stopping at edges that pass Cut.
- Set Handles bends a path into Bezier stretches between per-point handles; Set Path Type turns a path Poly or Bezier; Path.HandlesLeft and Path.HandlesRight read them.
- Sweep Along Path takes an optional Up per Point: the profile's up faces it on each stretch, else it turns as little as possible from the stretch before.
- ClusterConnected(points, starts, ends, distance) groups points joined by edges whose cluster middles are closer than Distance.
