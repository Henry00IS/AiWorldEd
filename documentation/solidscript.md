# SolidScript

SolidScript builds level geometry from a list of command lines: add a **SolidScript** generator to a solid model, press **Edit Script**, and every line you add turns into brushes in the viewport as you type.

## Writing a script

Double-click a command in the palette, or drag it in, to add it below the current line. Double-click a line to change its values. Blocks such as Repeat, Transform or If hold the lines up to their End. Move By, Move To, Rotate By, Rotate To, Scale By, Scale To, Align To, Mirror, Resize and Matrix are flat lines with Of, and do not take an End. A block with nothing inside is no mistake: it does nothing, and the Output shows a ⚠️ warning with a link to its line. With several lines selected whose blocks are whole (every If with its End), double-clicking a block command wraps them: it goes above the first line and its End below the last. When the selection cuts a block, the command goes below the current line as usual.

<details>
<summary>More Details</summary>

- Scripts use the editor's axes: X right, Y up and Z toward the front, so a Cube of `1, 2, 3` is 2 metres tall and `[$Box.Size]` is width, height and depth. Flat outlines are drawn with their own X and Y: Linear Extrude lays them on the ground (their Y running to the back) and pulls them up, Rotate Extrude spins them around the upright Y axis with their Y as the height.
- Fields take plain values (`2`, `1, 0, 0`), vectors in brackets (`[20, 30, 10]`, the same as `[=Vector(20, 30, 10)]`; any bracket that works out to exactly three numbers, such as `[[X], 0, 2]`), lists of vectors (`[1, 2, 3], [4, 5, 6]`), variables in brackets (`[Width]`) and formulas after an equals sign (`[=[Width] / 2]`). Every field reads `[names]` and `[=formulas]`, the Name of a building block too (`[Width]` with Width 15 names it `15`; a Brush there stops with `Name needs a Text or Number, not a Brush`). Only fields that name a variable a line writes (Set's Variable, every Into, Top, Sides and the like) or that define a name or setting the editor reads before the run (a Function's name and inputs, a Part's name, the settings of an Input, Input Group and Input Note, and the input a handler, Set Input or Show Inputs When works on) are used as typed; write `$[` for a literal bracket elsewhere. Text inside a formula takes double quotes, such as `[=IsString("3e")]`; bare words there are names, so `3e` or `hello` get an error that shows the quoted form. Single quotes are kept for later use.
- Only the commas typed in a field separate list items; a value is never split again, so For Each In `[Text], 23` with Text set to `Hello, World` walks `Hello, World` and `23`. Write `$,` for a comma inside an item, such as `a$, b, c` for the two items `a, b` and `c`. `[=Split([Text], ",")]` splits text, `[=Join([List], ", ")]` joins a list, and `[=Parse([Text])]` reads text like a typed field: `4,5,5` gives a vector and `5+5` gives 10.
- A script that builds nothing runs and shows its output with a warning, for trying out lines. An error keeps the output and variables from before it.
- Variables have no declared type, like `var` in other languages: any line may give a variable any kind of value, and a later line another kind. Left empty, a Set's Value gives empty text. **Clear Variable** empties a variable the way that fits what it holds: a list or vector becomes `[]`, a number 0, a Yes/No No and anything else empty text, and a name no line set becomes `[]`; **Delete Variable** forgets it. Commas typed outside brackets in a Value make a list, each item read on its own: `[5,3,4],zu,45,[4,5,6]` is a vector, the text `zu`, the number 45 and another vector, while `2,3,4` is still a vector and one item stays one value. Write `$,` for a comma inside a text, such as `Hello$, World`; `Hello, [Name]` is a list of two items. Clicking the Value of a Yes/No suggests Yes and No.
- Every command declares which kinds each field takes and what each field naming a variable gives. A line given a kind it cannot use stops with a plain message, such as `Of needs a Brush, Face or Text, or a list of them, not a Yes/No`; formula functions declare theirs too, so `Abs()` given a Brush stops the same way. While you type, the editor follows the script without running it and knows what kinds each name may hold at the caret: through If and Else, loops, Functions (per Call, and what each Return gives back) and Parts. An If narrows what it tests: inside `If [Henry] > 3` and its Else, Henry is a number; inside `If IsNum([V])`, V is a Number, and inside `If IsFace([X])`, X is a Face; a branch no run can take, such as `If 1 == 2` or a test a script Input's kind rules out, is skipped. Hover, the **Variables** tab and autocomplete show every kind a name may hold, such as `Number or Text`, each with the write that gives it and its line, such as `Brush: What is made of Cube (line 3).` or `Number: Set to 15 (line 3). Brush: What is made of Cube (line 5).` after an If and Else; clicking a name in the Variables tab goes to the last such write, and a wavy underline only appears where no way through the script gives a usable value.
- Fields that take one of a few words, such as Anchor, Which, How, a generator's choices or a texture name, take a Text or a Number; a Brush or a list there stops the line with `… needs a Text or Number, not a Brush`. A block's Name names everything it builds: a named Linear Extrude, Rotate Extrude or Offset passes its Name to every piece, and without one each outline keeps its own; Point only adds a corner, so it has no Name or Into. A Repeat or For Each counter lives in its loop, so a Function called inside the loop does not see it. The editor's hints tell item writes such as `Set Points(0)` as **Set**, not as an input passed in. Mistakes name the line and field and say what to do, such as `division by zero; check that what is divided by cannot be 0` or `a closing ")" is missing at the end`.
- Names ignore case: `[count]` and `[Count]` are one variable, and `sin(65)` is `Sin(65)`. Write them in PascalCase, such as `[StepHeight]`, `[Local.Width]`, `[Persistent.Presses]`, `Function Staircase` and `CharacterCode("A")`, like the examples do; the explorer keeps the spelling of the first Set or Input.
- Functions such as `Sin`, `Lerp`, `Remap`, `Split` or `TimeText` work in formulas; hover one in the suggestions to see what it does. `ItemOr([List], 5, 0)` reads an item with a fallback when there is none.
- A Texture field in a line's window has **Pick** and **Type**: Pick uses the same texture picker as the inspector and stores the texture's full library path; Type takes a name, a variable such as `[Wall]` or a formula. A field whose text uses `[` opens on Type.
- While a field is typed, suggestions follow the caret: a field that takes a few words, such as Which of Select Faces, lists them first; after `[` the matching variables, system values and functions show; inside any call, such as `[=Clamp(`, a hint under the field shows the full signature, such as `Clamp(Value: Number, Min: Number, Max: Number) -> Number`, with the input being typed in bold, that input's kind and meaning, and what the function does; it follows the caret as commas are typed, also in nested calls, and the script's own Functions show their inputs. Fields that name a variable a line writes, such as Set's Variable, every Into, Extrude Face's Top and Sides, Inset Face's Inner and Ring, Scatter Points' Normals, Result In, the List of the list lines and the Counter, Item and Key of Repeat and For Each, suggest the script's variables bare, without `[ ]`, so one can be reused; Inputs, functions and system values are left out. Set's Variable also offers the `$Selected` lists and, after a dot, only what leads to a value a line can set: `Brush.` offers Faces, Edges, Vertices and Data, `Brush.Edges.` offers First, Last, Faces, Parent and Data, and a vector variable offers X, Y and Z. Click a suggestion, or press Enter or Tab, to write it at the caret. Entering or clicking a field whose text before the caret ends with `[` (not `$[`) opens the suggestions again.
- **Stop Script** ends the script there, also from inside a Repeat or a Function, and keeps what it built. Run shared lines from many places with a Function and Call. A mistake always stops the script and highlights its line; there is no error catching.
- Shift+click or Shift+↑/↓ selects lines and Ctrl+click picks single lines; dragging any selected line moves them all, picked lines squashed together where they land, as one undo step. Ctrl+C, Ctrl+X and Ctrl+V copy, cut and paste them, also between scripts, and Ctrl+D duplicates them. Space adds an empty line above the current line and moves there; Shift+Enter or Insert adds one below.
- **F4**, **Ctrl+/**, **Off / On** in the toolbar or **Turn Off** in the right-click menu turns the selected lines off and on: they stay, are saved and synced, but do not run. Only the selected lines change: turning off a block line such as If also turns off its End and Else, and the lines inside keep running without the block; turning it on again turns its off End and Else back on when it has no End. Select the block with its contents to turn it all off. An off line is ignored everywhere, not just when the script runs: the names it would set, an off Function or Part, and its fields leave autocomplete, the Variables tab, the kind and mistake checks and the squiggles, and an off Input line shows no input in the inspector. **End** in Logic adds an End by hand when one is missing. A **Note** line holds a comment.
- In the help panel and a line's manual, every block name is a link: clicking it selects that block in the command list, scrolls to it and shows its help. The search is cleared only when it hides that block.
- In a shared room, script edits sync line by line: two people changing different lines both keep their change, the later write wins on the same line, and Undo only reverts your own lines. When someone else edits, your scroll position, current line, selection and an open configurator stay put. Breakpoints stay on your computer; turned-off lines are part of the script and sync.
- The script has its own undo history, apart from the level's: while the editor has focus, Ctrl+Z undoes and Ctrl+Y or Ctrl+Shift+Z redoes script edits only (typing, inserting, deleting, moving, Off/On, a line window's OK, paste), and level undo never changes the script.
- **New** starts an empty script and **Examples…** opens a ready one; both can be undone with the script's undo.

</details>

## Running and debugging

The script runs on every change. **Start** builds everything, **Debug** builds one solid at a time, **Step** builds the next one, and **Stop** shows the whole script again.

<details>
<summary>More Details</summary>

- A script may make at most 10,000 brushes, a mesh may have at most 1,000,000 triangles, a list may hold at most 100,000 items, functions and parts may run 256 levels deep, Repeat and For Each run at most 10,000 rounds, and a run stops after 10,000,000 steps of work. A line that hits a cap names the line and what to change.
- **F9** sets a breakpoint on the current line; Start and Debug pause before it runs.
- **Ctrl+F10** builds up to the line at the cursor.
- **Trace** marks the lines the debugger has passed.
- A small **×N** at the end of a line says how often it ran; hover it for its time.
- Drag the splitters beside the palette, beside the help column and above the output to resize them; the editor keeps the sizes for next time.
- The inspector's **Script** row shows the script's size and, under it, its messages: why the script may not be used in this step (such as a modifier-only script in a generator), then the script's error in red directly below; with neither it shows no message.
- The **Settings** tab holds **Can Be Used As** (Generator, Modifier; the use of the step you opened stays on, as in the inspector) and an **Author** line saved with the script. Both are script edits, so Ctrl+Z in the editor undoes them.
- The **Variables** tab lists every name with its value at the step shown, and the **System** values such as `$Time.Year`, `$Editor.Version` or `$Box.Width`. The generator examples size themselves from `[$Box.Width]`, `[$Box.Depth]` and `[$Box.Height]`; where a script runs without a box, such as a modifier, those values read as 1 and the Output shows a ⚠️ warning on the line instead of stopping. While you edit a script that Can Be Used As Modifier, a check that does not run the script looks for lines a modifier would run that read Box values (it follows If Used As and its Else and skips off lines) and lists them as ⚠️ warnings in the Output; it waits until typing pauses and the page is idle.

</details>

## Inputs

**Input** lines become fields in the inspector, so the same script builds many variants: a staircase with a Steps count, a column with a Height.

<details>
<summary>More Details</summary>

- A **curve** input opens the curve editor; read it with `CurveAt(curve, x)` or `ProfilePoints(curve, height, radius)`.
- A **texture** input picks a library texture; wrap brushes in a **Texture** block, such as `Texture [Wall]`, to paint every face with it. An inner Texture block wins, and brushes outside keep the generator's texture. **Texture Faces** gives the faces Select Faces picked their own texture. **Box UVs** gives the faces Select Faces picked texture coordinates projected from the side each face faces most. **Project UVs** gives them coordinates from a Box, Planar, Cylinder or Sphere projection (Box uses the same Overhead, Front and Side views as Bevel, from the way each face looks). **Unwrap**, **Pack Islands** and **Transform UVs** lay those islands flat, pack them into 0 to 1, or move, scale and rotate them. Brushes stay brushes; meshes stay meshes.
- **Input Group** shows the inputs inside it under a heading, **Input Row** puts them side by side, **Show Inputs When** shows them only while another input has a given value, or any one of several values written with commas, and **Input Note** shows a line of text among them.
- When Input Changes and When Button Pressed blocks can check and change inputs.
- **When Baked** runs just before the generator is baked, so a light preview can bake as a detailed version; undo brings back the old inputs.
- Values stored as `Persistent.Name` stay between runs.

</details>

## Brushes, faces and points

Brushes, faces, edges and corners are values, like numbers and text. A dot reads their parts: `[Top.Normal]`, `[Face.UVs]`, `[Brush.Faces.Count]`, `[Edge.Length]`, `[Faces.Center]` of a whole list, and `[Brush.Vertices.Positions]` through a list. On one vertex it is `[Vertex.Position]`; the singular after Vertices is a mistake, because Vertices is a list. Set `[Face.UVs]` to a list of U and V pairs, one per corner; a brush face must have a planar mapping or the line stops. `[Face.Data.Height]` keeps your own values on one. Set through a list writes every item, so Set `Brush.Edges.Data.Kind` to `trim` marks every edge of a brush, and `[Brush.Edges.Data.Kind]` reads one value per edge. System values start with `$`: `[$Selected.Faces]` is what the last **Select Faces** picked, `[$Selected.Brushes]` what the lines below work on, `[$Input.Brushes]` what a modifier receives. In a **Select Faces** Where condition the face being tested is `[$Face]` and `[$Index]` is its number from 0; **Select Edges** uses `[$Edge]` and **Select Vertices** uses `[$Vertex]`. `[$X]`, `[$NZ]` and the other short fills stand for `[$Vertex.Position.X]`, `[$Face.Normal.Z]` and so on. Fields worked out once per element, such as **Where** on Select Faces and **Distance** on Displace, show a green outline and a 🔁 icon in the inspector and in the script listing. `.Data` holds only your own values; built-in facts are members such as `[Face.Normal]` and `[Face.UVs]`.

<details>
<summary>More Details</summary>

- **Select Faces** picks faces into `[$Selected.Faces]` and into its **Into** variable. Which is a preset that equals a written-out Where: **All** keeps every face, **Facing Up** equals `Facing([$Face.Normal], Vector(0, 1, 0))`, and **Top** equals `HasTag([$Face.Tags], "Top")`. Which **New** keeps only faces made since the previous Select Faces. **Where** is a 🔁 condition each remaining face must pass, with `[$Face]` and `[$Index]`. Left off, it keeps what Which picked. Helpers such as `Facing()`, `InBox()`, `Near()`, `EveryNth()` and `HasTag()` work in Where, If and every other condition field. To pick faces of one brush, set Of, such as Of `[Knob]` or a Name. To walk a pick later, write it Into a variable and For Each over that list: `[$Selected.Faces]` is the last Select Faces, including one made inside a loop. Select Brushes, then Select Faces, then Select Edges narrows: faces of the picked brushes, then edges of those faces. Empty Of on Select Edges uses `[$Selected.Faces]` when faces are picked.
- **For Each** walks any list: For Each `[Face]` In `[$Selected.Faces]`, with an optional **Key** for its number. In a Data value it walks the keys. `[$Selected.*]` carries from round to round and stays after End, so a later round can add to or move what an earlier round picked. Write a pick Into a variable when you want to keep it through later Select lines.
- Every face command takes **Of**: a face, edge, brush, a list of them, or a brush **Name** such as Knob (in any case, also the shapes of a Part by its name). Empty takes `[$Selected.Faces]`. See the Panel With Knobs example.
- **Place On Face** builds the shapes inside standing on its face the way they stand on the ground (Y out of the face), with a Lift.
- **Place At Points** builds the shapes inside at each point in At, a list of vectors such as `[Spots]` from Scatter Points. Optional Directions (one per point, such as the Normals list) turns up along that way, and Lift moves them out along up.
- Pick faces, edges or vertices with **Select Faces**, **Select Edges** or **Select Vertices**, then operate: **Extrude Face**, **Scale Faces**, **Inset Face**, **Bevel Edges**, **Delete Faces**, **Texture Faces** and **Box UVs** use that pick when **Of** is empty. **Extrude Face** names its new brushes (**Into**), their end faces (**Top**) and side faces (**Sides**); **Scale Faces** scales each picked face about its center (a brush stays a brush); **Inset Face** names **Inner** and **Ring**; **Bevel Edges** names its new faces and skips edges of faces it made itself. **Inset Face** and **Delete Faces** work on a mesh; a brush stops, with a hint to wrap it in **Mesh From Brushes** first.
- **Scatter Points** spreads points into a list of positions. **Where** chooses how: **On Faces** (the default) spreads them over faces, more on bigger ones, and writes **Normals**; **Inside** fills a brush or mesh; **In Box** fills a box of Size; **Grid** lays Counts points in that box. Unused fields stay hidden. Of empty uses [$Selected.Faces]. The same Seed gives the same points for the random modes.
- **Hull** wraps the brushes, Point lines and optional **Points From List** between it and its End in one convex solid. Hand it the list Scatter Points writes, such as `Hull` From `[Spots]`, to wrap those points; they must not all lie in one plane, so scatter on more than one face. **Polyhedron** also wraps a point list, when you are listing corners yourself.
- **Find On** looks at the faces in Of, or [$Selected.Faces] when Of is empty: **Closest** (the default) picks the nearest point to From, **Along Ray** follows Direction and picks the first face it meets. It can write the point, Distance, Normal, Face and Hit.
- **Clip** cuts the brushes and meshes in Of, or [$Selected.Brushes] when Of is empty, with a plane. Through is a point on the plane. Normal is the way the part you cut away faces; the other side stays. A brush stays a brush, a mesh stays a mesh, and a closed mesh gets a new face over the cut.
- **Transform** changes the space that the lines between it and its End work in. Move, Rotate and Scale on that line are applied in that order after On. On takes a face (the same frame as Place On Face) or a brush (its center with world axes); leaving On off keeps the parent space. What the lines build is stored in ordinary script space. Transform never groups brushes for CSG.
- **Move By**, **Move To**, **Rotate By**, **Rotate To**, **Scale By**, **Scale To**, **Align To**, **Mirror**, **Resize** and **Matrix** are flat lines with **Of**: they change the brushes, meshes or points already named there, or `[$Selected.Brushes]` when Of is empty. Without Into the change happens where the items already are; with Into the originals stay and the copies are only in that variable. **Move By** is a distance in metres in the current space, always literal, no matter how small the brushes are. **Move To** places the combined center (the middle of the box around the selection, the same middle a Center, Center, Center anchor uses) at a point in script space. **Rotate By** turns around the origin of the current space; **Rotate To** turns around that combined center. **Scale By** multiplies size from the origin of the current space; **Scale To** stretches about the combined center to an exact size in metres. **Align To** turns Of so its up (Y) points along a direction, such as a face's `[Face.Normal]`. **Resize** also stretches Of to an exact size, about the origin of the current space, and can keep proportions or leave an axis alone. **Matrix** applies a 3 by 4 matrix, including shear.

</details>

## Paths and meshes

**Path** writes a list of points along a **Line**, **Arc**, **Spiral** or **From Points**, and **Curve To Mesh** sweeps a circle or your own outline along that list, such as a rail or a pipe. Points are vectors in brackets separated by commas, such as `[0, 0, 0], [1, 0, 0], [2, 1, 0]`, or a list variable such as `[Path]`; a Profile outline ignores z.

<details>
<summary>More Details</summary>

- Each stretch becomes one solid, cut on the mitre so the pieces meet; **As Mesh** builds one mesh instead.
- **Path** writes points to Into (Path by default). Shape **Line** (the default) walks from From to To; **Arc** turns around Center facing Normal, from Start by Sweep degrees; **Spiral** also climbs Height and can change radius over Turns; **From Points** uses the corners in Points, and Radius rounds them (Sides segments on each corner, Closed joins the last back to the first). Count is how many points Line, Arc and Spiral write. Unused fields stay hidden.
- `Resample(points, count)` spaces points evenly along a path, and `PathLength(points)` measures it. `PathAt(points, amount)` and `PathDirection(points, amount)` give the point and the way the path faces at a fraction of its length, and `TrimPath(points, start, end)` keeps one stretch.
- `Noise(x, y, z, scale, seed)` is a smooth random field from 0 to 1, and `Hash(value, seed)` is a number from 0 to 1 from any value. `Random(min, max, seed)` can be two vectors, `Shuffle(list, seed)` shuffles a list, and `Nearest(points, point)` is the index of the closest point. `RotateVector(vector, axis, degrees)`, `Angle(a, b)`, `Project(point, through, normal)` and `Reflect(vector, normal)` work on vectors. For a yes-or-no chance, write `Random(0, 1, seed) < 0.3`.
- **Grid Mesh** builds a mesh of quads in a plane: Size is width, height and depth, with one length at 0 so the grid is flat (2, 0, 2 on the ground, 2, 2, 0 for a wall facing the front). Columns and Rows are how many faces there are, and Anchor works like Cube.
- **Mesh** and **Mesh From Brushes** are the way a shape becomes a mesh. **Mesh From Brushes** bakes the brushes between it and its End into one mesh, cutting them the same way the editor does, including Subtractive and Intersecting modes and Group; only the brushes inside the block are baked. **Subdivide**, **Smooth Mesh**, **Displace**, **Flip Faces** and **Merge By Distance** then change that mesh; a brush stops, with a hint to wrap it in **Mesh From Brushes** first. **Displace** moves the vertices Select Vertices picked, or every point when none are picked. **Flip Faces** flips the faces Select Faces picked, or every face when none are picked.

</details>

## Generator or modifier

A script can be a **generator**, which builds new geometry from nothing, or a **modifier** on a brush, mesh or group, which works on what it is added to. **Can Be Used As** on the Script row says which uses a script allows, and **If Used As** lets one script do something different in each.

<details>
<summary>More Details</summary>

- Generator is on for every script that sets nothing. A script that does not allow a use is refused there with a message saying which box to turn on; the use a step already has stays on.
- Add a SolidScript modifier from **Add Modifier** on a brush, mesh, group or modifier volume. The old generators still cannot go on brushes or groups.
- As a modifier, the brushes it receives pass on unchanged unless the script has an **Input Brushes** line. What the script builds is added, with the script origin at the center of what it receives; Operation picks whether it is added, cut out or intersected.
- `[$Script.Usage]` is Generator or Modifier. `[$Input.Brushes]`, `[$Input.Faces]`, `[$Input.Min]`, `[$Input.Max]`, `[$Input.Size]` and `[$Input.Center]` describe what a modifier receives (all zero for a generator), and **Input Shapes** builds copies of those brushes to move, mirror or cut.
- The **Pedestal** example works both ways: as a generator it builds a box on a slab, as a modifier it puts the slab under the brush.
- **Input Brushes** passes the received brushes on, with their textures and materials. A **Transform** around that line, or a **Move By**, **Move To**, **Rotate By**, **Rotate To**, **Scale By**, **Scale To**, **Mirror**, **Resize**, **Align To** or **Matrix** of the copy, moves it. The first one that runs changes them; each later one adds a copy. Textures is Move With Shape or World Aligned; Readable Text flips U on a mirrored copy so lettering stays readable; UV Shift U and V move the texture of that pass by that many tiles. Clip of [$Input.Brushes] above this line cuts the received brushes the same way. **Built-In Modifiers** in the Examples window rebuilds Shear, Linear Array, Radial Array, Transform Array and Mirror this way, including Mirror Bisect and Flip. They match the built-in inspectors; a few behaviours still differ (the arrays measure the whole input, not each piece; Mirror places its plane on the received brushes, not the modifier volume box).

</details>

## Examples

The **Examples** window holds showcase scripts such as the Spiral Staircase, small lessons (an irregular rock from Hull, a tapered box, a rounded rail, a hilly floor), and the built-in generators and modifiers rebuilt line by line, so you can see how they work and change them.
